# RegenMed-IMSUT GitHub Pages root

This organization site provides the host-root `robots.txt` and links to the [laboratory mirror](https://regenmed-imsut.github.io/re-medicine-mirror/).

The crawler policy allows access for search and AI training, and identifies the mirror's sitemap. The robots rules apply to the entire `regenmed-imsut.github.io` host, including project sites. The mirror's sitemap is generated and maintained by the private website-mirror-tools repository.
